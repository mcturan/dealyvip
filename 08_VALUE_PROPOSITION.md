# Value Proposition

## Purpose
Define the customer value created by DealyVIP.

## Initial Direction
The emerging value proposition combines:

- Information
- Trust
- Local access
- Verification
- Coordination
- Practical assistance

## Requirement
The final value proposition must distinguish:
- what DealyVIP itself does,
- what it coordinates,
- what requires licensed or regulated professionals,
- what cannot yet be promised.
