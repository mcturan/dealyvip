# DealyVIP — Project Foundation

## Purpose
This repository is the strategic and operational source of truth for the DealyVIP project. It contains the decisions, research framework, business model, service definitions, information architecture, content standards, and implementation requirements that will later guide website and brand development.

## Current Stage
Sprint 1 — Project Identity & Working System.

## Operating Model
- Human Project Owners
- Execution Agent: Antigravity CLI / Gemini 3.1 Pro
- Source Control: GitHub
- Working method: sprint-based, documentation-first, review before the next sprint

## Repository Rules
1. Do not invent facts, capabilities, partnerships, legal authority, or market coverage.
2. Prefer a small number of living documents over many fragmented files.
3. Update the relevant source-of-truth document instead of duplicating information.
4. Record material decisions in `DECISIONS.md`.
5. Do not begin website implementation unless a later sprint explicitly authorizes it.

## Document Order
The documents in this folder are intentionally numbered. Unless a sprint prompt states otherwise, complete and review them in numeric order.
