# Target Markets

## Purpose
Define the initial geographic scope and language logic.

## Initial Markets
1. Türkiye
2. Ukraine
3. Russia
4. Iran

## Initial Strategic Rule
The project begins only with markets where a credible operational path, local access, or support capability can be established.

Geographic inclusion does not automatically mean that every service is available in that market.

## Language Direction
The language model will be determined by:
- country being discussed,
- target audience,
- search intent,
- operational relevance.

English is expected to be a core language, but the project should not assume that every page must exist in every language.

Detailed language architecture will be decided in a later sprint.
