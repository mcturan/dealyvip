# Domain Activation Checklist

1. [ ] Domain selection confirmation.
2. [ ] Domain ownership verified.
3. [ ] DNS provider pointed to Cloudflare.
4. [ ] Cloudflare custom domain attached to the Pages project.
5. [ ] Required DNS validation completed.
6. [ ] HTTPS edge certificates active.
7. [ ] `SITE_URL` environment variable properly configured in Cloudflare Pages.
8. [ ] Canonical verification (inspect production `<link rel="canonical">`).
9. [ ] Sitemap verification (check `/sitemap-index.xml`).
10. [ ] `robots.txt` verification (check `/robots.txt`).
11. [ ] `hreflang` verification across localized routes.
12. [ ] Structured data URL verification (JSON-LD outputs).
13. [ ] Search Console property addition (Domain level).
14. [ ] Bing Webmaster Tools optional addition.
15. [ ] Final indexing review and monitoring.
