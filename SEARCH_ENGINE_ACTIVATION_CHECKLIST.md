# Search Engine Activation Checklist

_Do not submit to search engines until the production domain is live, DNS is stable, and `SITE_URL` is verified._

1. [ ] Setup Google Search Console (Domain property preferred via Cloudflare DNS integration).
2. [ ] Setup Bing Webmaster Tools.
3. [ ] Submit `sitemap-index.xml` to GSC.
4. [ ] Submit `sitemap-index.xml` to Bing.
5. [ ] Review `robots.txt` fetch in GSC to ensure no blocking.
6. [ ] Review Canonical URL mapping via GSC URL Inspection.
7. [ ] Verify initial indexing status after 72 hours.
8. [ ] Establish coverage monitoring protocol.
