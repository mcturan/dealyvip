# Service Status Matrix

## Purpose
Provides a consolidated view of service availability across target markets based strictly on validated operational evidence.

## Status Definitions
- **ACTIVE:** Verified operational path exists.
- **COORDINATED:** Verified partner exists.
- **PILOT:** Delivery path exists but is untested.
- **RESEARCH REQUIRED:** Plausible, but lacks verified evidence.
- **NOT AVAILABLE:** Should not be offered.
