# DealyVIP Deployment Runbook

## Overview
DealyVIP is deployed as a static site generated by Astro. The site is served using Nginx from a controlled release directory (`/var/www/dealyvip/releases/`). The active release is managed via a symlink (`/var/www/dealyvip/current`).

## Prerequisites
- Node.js & npm installed
- Nginx installed and configured
- User must have `sudo` privileges to reload Nginx

## Deployment Steps
To deploy the latest changes from the `main` branch:

1. Ensure your local Git repository is up to date and clean.
2. Run the deployment script:
   ```bash
   ./deploy.sh
   ```

### What happens during deployment?
1. `npm run build` is executed.
2. A new timestamped directory is created in `/var/www/dealyvip/releases/`.
3. The `dist/` artifacts are copied into the release directory.
4. The `/var/www/dealyvip/current` symlink is repointed.
5. `nginx -t` verifies the configuration.
6. `systemctl reload nginx` is invoked to serve the new release.

## Error Handling
If the build fails, the deployment script terminates immediately and the old release continues to serve traffic.
If `nginx -t` fails, the Nginx reload is aborted.
